Security Guide & Jargon Buster

Clear, plain-English explanations of Veilguard's cybersecurity terms and tools

🧬 Digital Fingerprint (SHA-256 Hash)

Endpoint Defense

What it is: A 64-character unique code computed mathematically from an executable file. Think of it as the file's digital DNA.

Why it matters: If a hacker alters even a single line of code in a program or disguises malware as a safe file (like calc.exe), its hash changes completely. Security tools check this hash against global antivirus databases to instantly spot known viruses.

🛡️ Website Sinkhole (0.0.0.0 Hosts Block)

Web Protection

What it is: A technique that maps dangerous website addresses to 0.0.0.0 (a dead-end address that goes nowhere) right inside Windows.

Why it matters: It protects you at the operating system level. Even if you accidentally click a malicious link in an email or a browser, Windows will refuse to connect, protecting you from malware downloads and credential theft.

🚨 LOLBAS Anomaly (Living-Off-The-Land)

Hacker Detection

What it is: "Living Off The Land" is when attackers use legitimate built-in Windows tools (like powershell.exe or cmd.exe) to do their dirty work instead of downloading their own suspicious files.

Why it matters: Veilguard detects when a non-technical user app (like Microsoft Word, Excel, or a Web Browser) secretly launches a command prompt in the background. That almost always indicates a malicious document or macro attack.

🎯 Security Vulnerabilities (CVE & CVSS)

Vulnerability Mgmt

What it is: CVE stands for Common Vulnerabilities and Exposures — an official international catalog of known software bugs. CVSS is the 0–10 score that rates how severe the flaw is (9.0+ is Critical).

Why it matters: When Veilguard scans open ports, it checks if the software running on them has known CVEs. If it does, hackers can exploit that flaw unless you update or patch the software.

🌐 Active Sockets (ESTABLISHED vs LISTEN)

Network Flow

What it is: A socket is a digital communication pipeline between an app on your computer and an outside server.

States explained:
• ESTABLISHED: An app is actively exchanging data with a remote server right now.
• LISTEN: An app has opened a port and is waiting like an open door for incoming connections (like a web server or game host).

📁 Untrusted Path / Suspicious Directory

Malware Hiding Spot

What it is: Legitimate installed software almost always runs from C:\Program Files or C:\Windows\System32.

Why it matters: Malware does not have administrator permission to install in Program Files, so it almost always hides in AppData\Local\Temp or user profile folders. Veilguard flags any network-connected app running from these temporary hiding places.

⚡ Threat Feeds (Abuse.ch URLhaus & ThreatFox)

Threat Intelligence

What it is: Global, open cybersecurity threat sharing projects run by the Bern University of Applied Sciences in Switzerland.

Feed types:
• URLhaus: Over 13,000 active websites currently distributing malware payloads.
• ThreatFox: Over 43,000 Command and Control (C2) servers that infected computers communicate with.

📊 System Risk Meter (0–100)

Health Metric

What it is: A composite 0–100 score calculated by correlating alerts across all Veilguard monitors.

How to interpret:
• 0–39 (Secure - Green): Healthy status. All running apps are in trusted paths with clean reputations.
• 40–74 (Elevated - Amber): Caution. An app is running from a temp folder or connecting to an unusual port.
• 75–100 (Critical - Red): Action required. Active malware, LOLBAS anomaly, or known botnet communication detected.
